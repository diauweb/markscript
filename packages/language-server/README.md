# @markscript/language-server

The Volar-based language server for MarkScript, including static compiler
diagnostics, TypeScript and Markdown services, semantic tokens, and
MarkScript-specific syntax features.

```sh
bun add @markscript/language-server
markscript-language-server --stdio
```

See the [MarkScript repository](https://github.com/diauweb/markscript) for the
server protocol and editor integration.
