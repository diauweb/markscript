# @markscript/language-server

This package gives the Volar language server for MarkScript.
It includes static compiler diagnostics, TypeScript and Markdown services,
semantic tokens, and MarkScript syntax features.

```sh
bun add @markscript/language-server
markscript-language-server --stdio
```

Refer to the [MarkScript repository](https://github.com/diauweb/markscript) for the server protocol and editor integration.
