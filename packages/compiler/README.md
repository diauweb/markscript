# @markscript/compiler

The parser, formatter, TypeScript checker, source mapper, and callable ESM
bundler for MarkScript documents.

```sh
bun add @markscript/compiler @markscript/runtime
```

`check` and `compile` perform static source processing. Running a compiled
document is trusted code execution. See the
[MarkScript repository](https://github.com/diauweb/markscript) for the compiler
contract and examples.
