# @markscript/compiler

This package gives the MarkScript parser, formatter, TypeScript checker,
source mapper, and callable ESM bundler.

```sh
bun add @markscript/compiler @markscript/runtime
```

`check` and `compile` process source code statically. A compiled document executes trusted code.
Refer to the [MarkScript repository](https://github.com/diauweb/markscript) for the compiler contract and examples.
