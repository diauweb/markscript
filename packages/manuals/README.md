# @markscript/manuals

The generated diagnostic catalog, tutorials, handbooks, and canonical `.ms`
manual sources for MarkScript.

```sh
bun add @markscript/manuals
```

The package exports the parsed manual catalog and exposes individual sources
under `@markscript/manuals/manuals/*`. See the
[MarkScript repository](https://github.com/diauweb/markscript) for catalog and
diagnostic conventions.
