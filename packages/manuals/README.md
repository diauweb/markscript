# @markscript/manuals

This package gives the generated diagnostic catalog, tutorials, handbooks,
and authoritative `.ms` manual sources for MarkScript.

```sh
bun add @markscript/manuals
```

The package exports the parsed manual catalog. Individual sources use the path `@markscript/manuals/manuals/*`.
Refer to the [MarkScript repository](https://github.com/diauweb/markscript) for catalog and diagnostic conventions.
