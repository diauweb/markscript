# @markscript/language-core

This package gives the shared Volar language plugin and TypeScript
projection adapter for MarkScript documents.

```sh
bun add @markscript/language-core
```

Language servers and editors use this package for the compiler's virtual TypeScript and Markdown views.
The Markdown views keep source offsets.
Refer to the [MarkScript repository](https://github.com/diauweb/markscript) for the editor architecture.
