# @markscript/language-core

The shared Volar language plugin and TypeScript projection adapter for
MarkScript documents.

```sh
bun add @markscript/language-core
```

Language-server and editor integrations consume this package to share the
compiler's canonical virtual TypeScript and offset-preserving Markdown views.
See the [MarkScript repository](https://github.com/diauweb/markscript) for the
editor architecture.
